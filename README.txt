漢字読み方クイズ

ファイル：
- index.html：画面構成
- style.css：デザイン
- script.js：クイズの動作
- kanji-data.js：漢字と読み方のデータ
- kanji_320.txt：漢字と読み方のテキスト一覧

使い方：
1. すべてのファイルを同じフォルダーに保存します。
2. index.html をブラウザーで開きます。
3. 「クイズを始める」を押すと、50問がランダムに出題されます。
4. 終了後に得点、正解・不正解、解答一覧を確認できます。
5. 「新しいランダムクイズを始める」で別の50問に挑戦できます。

注意：
この一覧は学習用の読み方セットです。漢字には複数の読み方があるものもあります。
